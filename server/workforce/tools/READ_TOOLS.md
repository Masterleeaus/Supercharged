## Binding notes

- The five bound tools read tables that carry a `company_id` column. No existing storage method filters by company (`server/storage.ts` and `server/storage/*.ts` are user-keyed). The handlers therefore take an injected `ReadStore` port (`read-handlers.ts`). A real adapter is still to be written, and no SQL was written here.
- Records with no table in `shared/schema.ts` are unbound. Mapping them to `contacts`, `leads` or `refunds` would change what the tool means, so those are left unbound.
